# Amna Khalid — Developer Portfolio

Responsive, minimal white-and-navy portfolio featuring 11 projects, skills, experience, and contact information. No screenshots, CV download, or stock images.

## Run locally
Open `index.html` in a web browser. No build tools required.

## Files
- `index.html`: page content and project links
- `styles.css`: layout and responsive design
- `script.js`: project filters and mobile navigation

## Publish using GitHub Pages
Create a new public repository named `amnaakd.github.io`, upload `index.html`, `styles.css`, and `script.js` to the repository root, then select **Settings → Pages → Deploy from a branch → main / (root)**. The resulting URL should be `https://amnaakd.github.io/` after deployment completes.

## Notes
Team projects are identified as collaborative work. Some academic projects have no public repositories, and no links have been invented. The page uses Google Fonts with system-font fallbacks.

Latest update: centered hero introduction and removed footer entirely.

## CV download
The homepage Download CV button links to `Amna_Khalid_CV.pdf` in the repository root. Keep this PDF alongside `index.html` when publishing.
